# YouTube Cookies on CLI/Server Guide

Getting YouTube cookies on a headless server without a GUI browser.

## 🚀 Quick Methods

### Method 1: Manual Paste (Recommended)
```bash
./bin/quick-youtube-cookies
```
**Easiest and most reliable method**

### Method 2: Full CLI Setup 
```bash
./bin/setup-youtube-cookies-cli
```
**Multiple options with guided setup**

### Method 3: Basic curl extraction
```bash
./bin/curl-youtube-cookies
```
**Limited functionality, works for public videos only**

---

## 📋 Method 1: Manual Paste (Easiest)

**On your local computer:**
1. Open YouTube and log in
2. Install browser extension:
   - **Chrome**: [Get cookies.txt LOCALLY](https://chrome.google.com/webstore/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc)
   - **Firefox**: [cookies.txt](https://addons.mozilla.org/en-US/firefox/addon/cookies-txt/)
3. Export cookies to a file
4. Copy the ENTIRE file content

**On your server:**
```bash
./bin/quick-youtube-cookies
# Paste the cookie content when prompted
# Press Ctrl+D when done
```

## 🌐 Method 2: File Transfer Methods

### SCP Upload
```bash
# From your local machine
scp youtube_cookies.txt user@server:/path/to/bot/
```

### SFTP Upload
```bash
sftp user@server
put youtube_cookies.txt /path/to/bot/
```

### SSH + Cat Method
```bash
# Copy cookie content locally, then:
ssh user@server
cat > /path/to/bot/youtube_cookies.txt
# Paste content, press Ctrl+D
```

## 🔗 Method 3: SSH Tunnel Method

**Terminal 1 (Local machine):**

## 🔄 Cookie File Format

Valid YouTube cookies must be in **Netscape HTTP Cookie File** format:

```
# Netscape HTTP Cookie File
# This file is generated by yt-dlp. Do not edit.

.youtube.com	TRUE	/	TRUE	1784797685	__Secure-3PAPISID	EXAMPLE...
.youtube.com	TRUE	/	TRUE	1784797685	__Secure-3PSID	g.a000EXAMPLE...
.youtube.com	TRUE	/	FALSE	0	PREF	f6=40000000&tz=UTC&hl=en
```

**Important cookies for authentication:**
- `__Secure-3PAPISID` - API session
- `__Secure-3PSID` - Secure session ID  
- `__Secure-3PSIDTS` - Session timestamps
- `VISITOR_INFO1_LIVE` - Visitor tracking

## ⚠️ Troubleshooting

### "Sign in required" Error
```bash
# Cookie format issue
head -1 youtube_cookies.txt
# Should show: # Netscape HTTP Cookie File

# Expired cookies - refresh them
./bin/quick-youtube-cookies

# Test basic connectivity
curl -I https://www.youtube.com
```

### "Bad Request" Error
```bash
# Check newline format (should be LF, not CRLF)
file youtube_cookies.txt
# Should show: ASCII text

# Convert Windows line endings if needed
dos2unix youtube_cookies.txt
```

### "HTTP Error 403" 
```bash
# IP/proxy blocking - check bot logs
# Enable delay between requests
echo "YOUTUBE_DELAY=10" >> .env

# Try different proxy
# Check proxy rotation logs
```

## 🛡️ Security Best Practices

1. **Use throwaway accounts** - Never use your main YouTube account
2. **Rotate cookies regularly** - Weekly refresh recommended  
3. **Monitor for blocks** - Watch for "Sign in required" errors
4. **Use rate limiting** - Set `YOUTUBE_DELAY=5` or higher
5. **Secure cookie storage** - Restrict file permissions:
   ```bash
   chmod 600 youtube_cookies.txt
   ```
